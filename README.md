# CSS Framework Lab

Four static pages: a project hub, matching Northstar designs in Bootstrap 5.3.3 and Tailwind CSS 4, and an interactive learning guide.

## Run

Open `index.html` in a browser, or serve this directory with `python3 -m http.server 8000` and open `http://localhost:8000/`. Internet access is needed for the framework CDN assets. The Tailwind Play CDN is intended for development and classroom demonstrations, not production deployment. For a production site, build a static Tailwind CSS file with the Tailwind CLI or a bundler.

## Publish

Upload the contents of this folder to a web host with directory index support. Keep the four `index.html` locations and relative paths intact. The host `io.vefskoli.is` requires your course account and its own publishing instructions; no deployment or peer feedback has been performed here.

## Review checklist

- Open the hub and all three project links.
- Resize both designs to narrow and wide widths, and compare content and layout.
- Hover and keyboard-focus the feature cards; test the mobile navigation.
- On the learning page, move the width slider and switch the theme.
- Check the source links in the learning guide.

Framework references are linked directly from the learning page.
